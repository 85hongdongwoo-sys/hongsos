동네에서 직접 뛰는 업체를 찾고 있어요. 조건이 맞으면 첫 3개월은 무료로 우리 동네 페이지에 연결해 드립니다.

이런 업체를 찾아요

  • 사장님이나 담당 기사가 직접 전화를 받고 상담하는 업체
  • 손님에게 출발 전에 예상 금액을 먼저 안내하는 업체
  • 사업자등록이 되어 있고, 등록한 지역에 실제로 출장을 가는 업체
  • 현장 사진이나 작업 전후 사진을 보내 줄 수 있는 업체
  • 불친절·바가지 민원이 들어오면 연결을 중단하는 데 동의하는 업체

무료 기간에 받는 것

  1. 우리 동네 페이지 등록

    업종과 지역 페이지 맨 위에 업체 이름과 번호가 올라갑니다.

  2. 연결 건수 공유

    매달 몇 명이 전화 버튼을 눌렀는지 알려 드려요.

  3. 3개월 뒤 선택

    계속할지는 그때 결과를 보고 사장님이 정하시면 됩니다. 자동으로 돈이 나가는 일은 없어요.

무료 등록 신청

신청서를 채우고 버튼을 누르면 내용이 적힌 문자 창이 열려요. 보내기만 누르면 신청 끝입니다.

출장 가능 지역

신청 내용은 업체 등록 확인에만 쓰고, 등록하지 않으면 바로 지웁니다.
